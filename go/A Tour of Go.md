- 패키지
	- `go`는 패키지로 구성되며 `main` 패키지에서 시작된다.
	- 패키지명은 `import` 경로의 마지막과 같다.
- imports
	- 여러 퍠키지를 `import` 할 시 괄호로 감싸진 `factored` 임포트 문을 사용할 수 있으며, 한 줄씩 따로 작성할 수도 있지만 기본적으로 `factored` 임포트 문이 권장된다.
- Exported names
	- 대문자로 시작되는 이름만을 외부에서 참조 가능하다.
- Functions
	- 함수는 0개 이상의 매개변수를 가지며 타입은 변수의 오른쪽에 위치한다.
	- 연속하는 두 개 이상의 같은 타입을 가진 파라미터는 마지막을 제외하고 타입을 생략할 수 있다.
	- 함수의 반환값은 여러 개 일 수 있다.
	- 리턴값에 이름을 부여할 수 있으며 리턴값의 의미를 나타내는 용도로 사용되어야 한다.
	- 리턴값의 이름은 함수의 상단에 선언된 변수처럼 취급되며, 인자 없는 리턴은 이름의 값이 반환된다. 이를 `naked` 함수라 한다.
	- `naked` 함수는 가독성을 위해 짧은 함수에서만 사용한다.
- Variables
	- `var` 키워드를 사용해 변수 목록을 선언할 수 있으며 함수 매개변수와 마찬가지로 연속하는 같은 타입의 변수는 마지막을 제외하고 타입 선언을 생략할 수 있다.
	- 패키지, 함수 레벨에서 사용 가능하다.
	- 변수는 초기값을 가질 수 있으며 초기값을 가지는 경우 타입을 생략할 수 있다. 이때 변수의 타입은 초기값의 타입으로 추론된다.
	- `:=` 키워드로 간략히 표시할 수 있으며 함수 외부의 문은 키워드로 이루어져 있기 때문에 함수 외부에서는 사용할 수 없다.
- Basic types
	```go
	bool
	
	string
	
	int  int8  int16  int32  int64
	uint uint8 uint16 uint32 uint64 uintptr
	
	byte // alias for uint8
	
	rune // alias for int32
	     // represents a Unicode code point
	
	float32 float64
	
	complex64 complex128
	```
	- `int`, `uint`, `uintptr` 타입은 32 비트 시스템에서는 32비트의 크기를 64비트의 시스템에서는 64비트의 크기를 가진다.
	- 특별한 이유가 없는 경우 정수형 타입은 `int`를 사용해야 한다.
- Zero values
	- 초기값 없이 선언된 변수는 변수의 타입에 맞는 `zero` 값을 가진다.
		- 숫자: `0`
		- 문자: `""`
		- 불리언: `false`
- Type conversions
	- `T(v)`: 변수 `v`를 `T` 타입으로 변환한다.
	- c 언어와는 다르게 Go에서는 서로 다른 타입의 요소 사이의 값 할당 시 명시적인 타입 변환을 해야한다.
- Type inference
	- 타입 없이 선언된 변수는 선언의 오른쪽에 위치한 값의 타입으로 추론되며,
	  숫자 상수의 경우 값의 정밀도에 따라 `int`, `float64`, `complex128`로 추론될 수 있다.
- Constants
	- 상수는 `const` 키워드와 함께 변수 선언과 동일하게 선언할 수 있다.
	- 상수는 높은 정확도의 값을 가지며 타입없이 선언된 상수는 `context`에서 필요한 타입을 가진다.

- For
	- `go`에서는 유일하게 `for` 만을 이용해 반복을 수행할 수 있다.
	- 세미콜론으로 분리된 세 가지 구성 요소로 이루어진다.
		- 초기화 문: 첫 반복 전 실행
		- 조건문: 매 반복 전에 평가됨
		- Post 문: 모든 반복의 마지막에 실행
	- 초기화는 변수 선언이며, `for` scope 내에서만 유효하다.
	- bool 조건이 `false` 이면 반복을 멈춘다.
	- 다른 언어(`C`, `Java`, `JavaScript` 등)와 다르게 세 구성 요소를 괄호로 묶지 않으며 `{}`는 필수다.
	- 초기화 문과 Post 문은 생략 가능하며 이 경우 세미콜론을 생략할 수 있다. (`while` 문이 이 방식으로 표기된다.)
	- 조건을 적지 않으면 무한 루프를 돌며, 간단히 무한 루프를 표시할 수 있다.
- If
	- `for` 문과 비슷한 형태로 표현식을 괄호로 묶지 않아도 되지만 `{}`는 필수이다.
	- 조건과 변수 선언을 축약할 수 있으며, 조건 내에 선언된 변수는 `if` scope 내에서만 유효한 값이다.
	- 선언된 변수는 `else` 블록 내에서도 유효하다.
- Switch
	- `go`에서의 `switch`는 다른 언어(C, Java, JavaScript 등)와 다르게 선택된 case만 실행하고 뒤의 모든 case는 실행하지 않는다.
	  때문에 break 문이 필요하지 않다.
	- `switch case`는 상수가 아니어도 되고, 관련된 값도 정수가 아니어도 된다.
	- `switch case`는 위에서 아래로 `case`를 평가하며 `case`의 평가가 성공 시 중지한다.
	- `switch`에 값을 생략할 수 있으며 이는 `switch true`와 같다.
	  `if-else` 체인을 간략히 표시하는데 사용할 수 있다.
- Defer
	- `defer`는 함수의 실행을 주변 함수의 반환 시까지 지연시키는 함수이다.
	- 지연 호출된 함수의 인자는 즉시 평가되지만 함수의 실행은 주변 함수의 반환 시 수행된다.
	- 지연 호출된 함수는 stack에 쌓이며 주변 함수 반환 시 `last-in-first-out` 순서로 수행된다.

- Pointers
	- 포인터는 주소를 나타내며, `&`는 피연산자의 포인터를 생성하고, `*`연산자는 포인터의 값을 나타낸다.
	- `*T` 타입은 `T` 값을 가리키는 포인터를 생성하며, `zero` 값은 `nil`이다.
- Strunts
	- 필드의 모음으로 `.`을 이용해 필드의 값에 접근할 수 있다.
	- 포인터를 이용해 `struct`의 필드에 접근할 수 있으며, `(*p).k` 형태로 사용해야 하지만 간단히 `p.k` 형태로도 사용할 수 있다.
	- `struct` 리터럴은 새로운 구조체의 필드들의 값 목록을 나열한다.
	  `Name:` 형태로 필드에 접근할 수 있으며 순서는 중요하지 않다.
	- `&` 연산자를 사용해 `struct`의 포인터를 만들 수 있다.
- Arrays
	- `[n]T` `T` 타입을 가진 `n` 개의 값 목록을 나타내며, 배열의 요소의 개수는 수정할 수 없다.
- Slices
	- 동적 크기를 가지며, `:`으로 구분된 하한부터 하한까지의 두 지수로 명시된 형태이다.
	  `a[1:4]` 형태로 작성하면 `a` 배열의 1부터 3까지의 새 슬라이스를 만든다.
	- `slice`는 값을 저장하지 않으며 배열을 참조하는 형태로 나타난다.
	  `slice` 내의 요소를 변경하면 참조하는 원본 배열의 값도 변경되며 같은 배열을 참조하는 다른 `slice`의 요소도 영향을 받는다.
	- `slice` 리터럴은 길이가 없는 배열 리터럴과 같은 형태로 표현된다.
	  하한 생략 시 기본으로 0을 가지고
	  상한 생략 시 참조하는 배열 혹은 `slice`의 길이를 가진다.
	- `slice`는 길이와 용량을 제공한다.
		- 길이: `slice` 요소들의 개수를 의미한다.
		- 용량: `slice`의 첫 번째 요소부터 세어나간 원본 배열에 포함된 요소의 개수를 의미한다.
	- `slice`는 용량만큼 확장 가능하다.
	- `slice`의 `zero` 값은 `nil`로 `nil slice`는 길이와 용량이 0이고 참조하는 원본 배열이 없다.
	- `make` 함수를 이용해 `slice`를 만들 수 있으며 인자로 전달한 타입의 `zero` 값을 가진 배열을 생성하고 생성된 배열을 참조하는 `slice`를 반환한다.
	- `slice` 내부에는 `slice`를 포함한 모든 타입이 들어올 수 있다.
	- `append` 함수를 통해 `slice`에 요소를 추가할 수 있다.
- Range
	- `slice`나 `map`을 순회할 때 사용한다.
	- `index`와 `value` 두 값을 리턴하며, 필요하지 않을 시 `_`를 사용해 생략할 수 있다.
- Maps
	- `key`와 `value`로 구성되며 초기 값은 `nil`이다.
	  `key`가 없고 추가할 수도 없다.
	- `make` 함수를 이용해 `map`을 만들 수 있으며, 초기값을 부여하고 `map`을 사용할 수 있도록 한다.
	- 리터럴은 `struct`와 유사하지만 키가 필수이다.
	  최상위의 형태가 단순 타입의 이름이라면 하위 요소의 타입을 생략할 수 있다.
	- 맵 요소에 접근 시 두 개의 선언을 작성하면, 두 번째 변수에 `map`에 해당 `key`의 존재 유무를 알려준다.
	  `map`에 해당하는 `key`가 없을 경우 값은 `zero` 값을 가진다.
	  ```go
	  // map에 값을 할당하거나 변경
	  m[key] = elem
	  
	  // 요소 검색
	  elem = m[key]
	  
	  // 요소 삭제
	  delete(m, key)
	  
	  // 두 개의 값을 할당
	  elem, ok = m[key]
	  // 또는 새로운 변수에 할당
	  elem, ok := m[key]
	  ```
- Function values
	- 함수는 값으로 취급되며, 다른 값들과 같이 전달이 가능하다.
	  주로 함수의 인자나 함수의 반환 값으로 사용된다.
	- 클로저 함수는 함수의 본문 외부의 변수를 참조하는 함수 값으로 참조하는 변수에 접근하거나 변수의 값을 할당할 수 있다.
	  이는 변수에 종속된 함수의 형태이다.
